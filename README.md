# Autoroo

Autoroo is a silly endless 3D browser-driving game: flip between lanes, jump cars
and buses, and outrun the traffic behind you. Gameplay is a deterministic 60 Hz
TypeScript simulation; Babylon.js renders relative to the player using bounded
object pools, while React owns the HUD and menus.

## Gameplay

- Hold Up to accelerate and Down to brake. Left and Right trigger a quick
  lateral barrel roll into the next active lane, including in the air. The
  physical lane sweep remains collidable, so an evasive move can be too late.
  Space jumps, and holding it hops again on each landing; Escape pauses.
- Distance is scored from the furthest metre reached. Jumping a car adds 100,
  jumping a bus adds 250, and a grounded adjacent-lane close pass adds 25.
- Road width follows an endless seeded 2→3→4→3→2 topology. Traffic and scenery
  are generated by absolute distance and never loop a prebuilt map.
- Slow driving triggers warned rear traffic. Traffic starts readable, ramps
  sharply through the first few kilometres, then approaches a bounded density
  without unbounded speed or pool growth.
- Every revealed ordinary row has a replayed ground route. Mandatory jump gates
  are locked only after their analytic takeoff window and a production-simulation
  witness both succeed from the exact reveal state. Ignoring that certified route
  can still put the player into a later losing state.

The personal best is stored locally as a validated, versioned record. There are
no accounts, network gameplay APIs, or score-writing browser tools. When WebMCP
is available, Autoroo exposes only status, start, pause/resume, and restart—the
same low-frequency actions visible in the interface.

## Run locally

Requires Node 22.

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Use Left/Right to flip lanes, Up/Down to control
speed, Space to jump, and Escape to pause.

## Verify

```bash
npm run typecheck
npm test
npm run lint
npm run check:assets
npm run build:static
```

The long-run suite is `npm run test:stress`. It generates one million road
modules and drives certificate-following bots for 100 km across each test seed
while asserting deterministic, bounded retained state.

## Assets and performance

The 12 curated GLBs under `public/models` are SHA-256 pinned in
`app/game/assets.ts`; that same manifest drives the Credits dialog. Tests reject
uncredited models, map/OSM data, and the non-redistributable London double-decker.
See `CREDITS.md` for attribution and modification details and `LICENSE` for the
preserved MIT notice covering adapted first-party Curbside Rush code.

Rendering uses a 1.5 device-pixel-ratio ceiling, fog-matched draw distance,
recyclable 40 m road tiles, pooled model instances, numeric swept colliders,
10 Hz HUD publishing, and adaptive resolution after sustained frame loss.

## Netlify

`netlify.toml` targets Node 22, runs `npm run build:static`, and publishes
`dist/client`. This is a static export with no account system, server function,
Netlify Next.js plugin, or runtime backend. Hashed models receive immutable cache
headers. Deployment itself is intentionally outside this repository task.

See `CREDITS.md` for source, licence, modification, and exclusion records.
