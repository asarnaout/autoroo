# Selected landing page

Final direction combines the user's centered, cinematic purple-city reference
with the googly-eyed cream/coral Autoroo sticker identity and the existing
gently moving `autoroo-stunt-v2.png` illustration.

The production scenes are `public/images/menu/autoroo-title-city.png` and
`public/images/menu/autoroo-title-city-portrait.png`. The logo is composited
into continuous illustrated sky so there is no checkerboard or matte rectangle.
The car/bus remains a separate animated image. All controls, personal best,
tagline and links remain real HTML. Image generation used the built-in tool;
the exact scene and asset prompts are saved in this directory.

The rejected navy logo fallback is retained here as design history and is not
used on the landing page. Earlier A/B/C mockups and failed cutout originals are
also preserved under `output/` as requested when committing all work.
